# 💸 Banking Demo Program

A simple **Python** banking system to manage accounts, deposits, withdrawals, and balances. Includes an admin system for managing user profiles and accounts. Data is saved in text files. 📄

## 🚀 Features
- 🔑 **User Login**: Secure login with username and password.
- 💰 **View Balance**: Check your account balance.
- 💵 **Deposit/Withdraw**: Perform transactions easily.
- 🛠️ **Admin System**: Manage user profiles, accounts, credits, and loans.
- 📄 **File Storage**: Data saved to `user.txt`, `account.txt`, `credit.txt`, and `loan.txt`.
